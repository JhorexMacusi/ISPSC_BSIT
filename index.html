How to Contribute

  1. Fork this repository on GitHub.
  2. Open your terminal (Command Prompt, PowerShell, or VS Code Terminal), then clone your forked repository: 
    git clone https://github.com/YOUR-USERNAME/ISPSC_BSIT.git
  3. After cloning, locate the folder named ISPSC_BSIT on your computer and open it.
    You can also open it using your terminal: 
    cd ISPSC_BSIT
  4. (Recommended) Open the project folder in VS Code for easier editing: 
    code .
  5. Go to student.json and add your information using this format: 
    {
        "name": "Your Full Name",
        "course": "BSIT",
        "yearLevelSection": "Your Year & Section",
        "github": "https://github.com/YOUR-USERNAME",
        "bio": "Short description about yourself",
        "photo": "images/your-image.jpg"
      }

    Make sure to keep valid JSON format and do not delete existing entries.

  6. Add your image inside the images folder.
  7. In the terminal (inside the project folder), stage your changes: 
    git add .
  8. Commit your changes: 
    git commit -m "Add portfolio: Your Name"
  9. Push your changes: 
    git push origin main
  10. Go back to GitHub and submit a Pull Request for review.
  11. For a more detailed guide, visit: W3Schools Git Fork Tutorial
